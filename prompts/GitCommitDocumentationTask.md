Этап 1. Проверить текущий статус Git

Перед началом выполнить:

Проверить:

наличие незакоммиченных изменений.

Проверить:

и:

Этап 8. Проверка перед commit

Выполнить:

git status

Проверить:

нет лишних файлов;
нет секретов;
нет временных файлов.

Проверить изменения:

git diff

Этап 9. Создать Git commit

После проверки изменений выполнить:

git add .

Создать коммит с понятным русским описанием.

Формат:

git commit -m "Краткое описание изменений"

Пример:

git commit -m "Добавлена структура документации проекта и AI контекст"
Правила написания commit сообщений

Использовать простой русский язык.

Хорошие примеры:

git commit -m "Создана базовая структура проекта"
git commit -m "Добавлена документация StreamPass"
git commit -m "Обновлена архитектура проекта"
git commit -m "Добавлены инструкции для работы с ИИ"
git commit -m "Добавлены скрипты автоматизации"
git commit -m "Исправлены ошибки в настройках проекта"
git commit -m "Обновлена конфигурация окружения"

Для текущей задачи использовать:

git commit -m "Добавлена документация проекта и AI контекст"

Этап 10. Отправить в удалённый репозиторий

Проверить ветку:

git branch

Если основная ветка:

main

выполнить:

git push origin main

Если используется другая ветка:

отправить её:

git push origin <branch-name>
Этап 11. Финальная проверка

После отправки:

git status

Ожидаемый результат:

nothing to commit, working tree clean

Проверить последний commit:

git log -1
