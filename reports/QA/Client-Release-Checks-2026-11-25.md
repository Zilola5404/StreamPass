# Проверки Windows и Android перед выпуском

Дата проверки — 25 ноября 2026 года.

| Область | Подтверждено локально | Осталось подтвердить на релизной сборке |
|---|---|---|
| Windows и TLS | Собрано ядро с `with_gvisor`, проверены DLL Wintun, IPC, правила, DNS и защищённая привязка к интерфейсу. Команда подключения в режиме relay отклоняет конфигурации без проверки TLS | Для действующих relay опубликовать настройки с доверенным сертификатом и правильным именем. При использовании pin текущая реализация сверяет отпечаток после обычной проверки сертификата. Затем подтвердить TLS, создание Wintun с правами администратора, реальный трафик, восстановление после сна и обрыва |
| Android UI | Orb учитывает системное уменьшение движения и отдаёт подпись, статус и действие средствам доступности | Сверить шрифт и иконки с первым референсом, а компоновку со вторым. Первый референс по сохранённому пути отсутствует. ADB показал пустой список устройств, поэтому плавность и читаемость на телефоне открыты |
| OTA | Приложение принимает только ссылки HTTPS с именем хоста и без встроенных учётных данных | На телефоне проверить установку следующего подписанного APK поверх предыдущего, сохранение данных и восстановление рабочей версии. Для восстановления через штатное обновление собрать предыдущий рабочий код с более высоким `versionCode` и той же подписью, проверить совместимость данных |
| SLA | Скрипт замера Connect связывает начало сессии с готовностью трафика. Отсутствующий результат ADB больше не считается успешным запуском | Зафиксировать один SHA, SHA-256 APK, версии ОС и сети. Измерить холодный запуск ≤2 с, Connect ≤5 с и восстановление реального запроса после обрыва ≤10 с. Подтвердить доступность ≥99,9% за 30 дней по внешним пробам API и relay, указав длительность потерь и пропуски метрик |

Порядок приёмки на устройстве: зафиксировать сборку и baseline, проверить запуск и соединение, проверить сон или смену сети, повторить запрос после восстановления, затем проверить обновление и восстановление версии. В итоговый отчёт внести измеренные времена и результат каждого шага.

## Повторная проверка Windows с правами администратора

На рабочем дереве обнаружено падение `sing-tun.NativeTun.Start`. В режиме AutoRoute библиотека регистрирует интерфейс через монитор, который ранее не передавался. Исправление передаёт монитор для регистрации адаптера без запуска отдельного наблюдателя сети.

Повторный запуск на Windows подтвердил создание Wintun, установку маршрута IPv4 и DNS, успешный запрос HTTPS к `ya.ru` в режиме DIRECT и подтверждение Stop. Инициализация ядра заняла 2,798 с по журналу. Этот замер относится к запуску ядра. Остаются проверка реального RELAY с доверенным сертификатом и восстановление после сна и обрыва сети. В сборку проверки входили ранее существовавшие локальные правки Go Core.
