Technical Specification
Версия 1.0
Статус: Approved
1. Цель проекта
Разработать кроссплатформенную систему интеллектуальной маршрутизации интернет-трафика, которая автоматически выбирает оптимальный маршрут для каждого соединения.
Основные цели:
обеспечить максимально стабильный доступ к зарубежным сервисам;
повысить вероятность успешного открытия сайтов и приложений при нестабильной мобильной сети;
сохранить прямое подключение к российским ресурсам;
полностью исключить ручную настройку пользователем.
2. Основные принципы
Пользователь нажимает одну кнопку:
Подключить
После этого система самостоятельно:
анализирует качество сети;
выбирает оптимальный relay;
выбирает маршрут;
переключает сервер при деградации;
обновляет правила;
собирает техническую телеметрию.
Пользователь ничего не настраивает.

[Unit]
Description=StreamPass API
After=network.target
[Service]

ExecStart=/root/StreamPass/server/streampass-api
Restart=always
Environment=JWT_SECRET=super-secret
[Install]

Потом

Установка StreamPass Relay на новый Ubuntu сервер (с нуля)
Шаг 1. Подключиться к серверу
На Windows открой PowerShell.
Подключись по SSH:
ssh root@IP_СЕРВЕРА
Например:
ssh root@212.43.159.198
Если спросит:
Are you sure you want to continue connecting?
введи
yes
Шаг 2. Обновить систему
Выполни:
apt update
apt upgrade -y
Шаг 3. Установить необходимые программы
apt install curl wget unzip openssl ufw -y
Шаг 4. Скачать Hysteria2
bash <(curl -fsSL https://get.hy2.sh/)
Проверить:
hysteria version
Должно вывести версию.
Шаг 5. Создать папку
mkdir -p /etc/hysteria
Шаг 6. Создать сертификат
Выполни:
openssl req -x509 -nodes -days 3650 \
-newkey rsa:2048 \
-keyout /etc/hysteria/key.pem \
-out /etc/hysteria/cert.pem \
-subj "/CN=StreamPass"
Проверить:
ls /etc/hysteria
Должно быть
cert.pem
key.pem
Шаг 7. Создать конфигурацию
Открой редактор:
nano /etc/hysteria/config.yaml
Вставь полностью:
listen: :443
tls:
cert: /etc/hysteria/cert.pem
key: /etc/hysteria/key.pem
auth:
type: password
password: streampass-secure-auth
obfs:
type: salamander
salamander:
password: streampass-relay-2024
bandwidth:
up: 1 gbps
down: 1 gbps
Сохранить:
Ctrl+O
Enter
Ctrl+X
Шаг 8. Создать systemd сервис
nano /etc/systemd/system/hysteria.service
Вставить:
[Unit]
Description=Hysteria2 Relay
After=network.target
[Service]
ExecStart=/usr/local/bin/hysteria server -c /etc/hysteria/config.yaml
Restart=always
RestartSec=5
[Install]
WantedBy=multi-user.target
Сохранить.
Шаг 9. Перезагрузить systemd
systemctl daemon-reload
Шаг 10. Включить автозапуск
systemctl enable hysteria
Шаг 11. Запустить сервер
systemctl start hysteria
Шаг 12. Проверить статус
systemctl status hysteria
Должно быть:
active (running)
Шаг 13. Открыть порт
ufw allow 443/udp
Шаг 14. Включить Firewall
ufw enable
Подтвердить:
y
Шаг 15. Проверить
ss -lunp | grep 443
Должно быть:
*:443
Шаг 16. Проверить журнал
journalctl -u hysteria -f
Должно быть:
INFO server up and running
Шаг 17. Проверить подключение
На Windows:
.\hysteria-windows-amd64.exe client -c .\hysteria-client.yaml
Должно появиться:
connected to server
Шаг 18. Проверить Android
Импортируй профиль:
hysteria2://streampass-secure-auth@IP_СЕРВЕРА:443/?obfs=salamander&obfs-password=streampass-relay-2024#StreamPass
Например:
hysteria2://streampass-secure-auth@212.43.159.198:443/?obfs=salamander&obfs-password=streampass-relay-2024#StreamPass
Шаг 19. Проверить IP
Открой:
https://ifconfig.me
Если отображается IP сервера — туннель работает.
Шаг 20. Если не работает
Проверь статус:
systemctl status hysteria
Посмотри журнал:
journalctl -u hysteria -f
Проверь открытый порт:
ss -lunp | grep 443
Проверь Firewall:
ufw status
Проверь, что UDP-порт 443 доступен:
tcpdump -ni any udp port 443
Если при попытке подключения появляются UDP-пакеты, значит клиент до сервера доходит.
