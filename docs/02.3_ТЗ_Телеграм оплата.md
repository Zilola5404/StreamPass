# ТЗ: Подключение оплаты через Telegram Stars + USDT для StreamPass MVP

## Цель

Реализовать прием оплаты **без ИП/ООО/самозанятости** для MVP StreamPass с автоматической выдачей подписки.

На первом этапе поддержать:

1. **Telegram Stars** (основной способ).
2. **USDT TRC20** (международный способ).

Backend проекта уже на **Go**. Необходимо добавить платежный модуль, webhook и активацию подписки.

---

# 1. Telegram Stars

## Что сделать

### 1.1 Создать Telegram-бота

Использовать существующий токен бота (передам отдельно).

### 1.2 Добавить команду `/buy`

Бот показывает тарифы:

* 1 месяц — 499 Stars
* 3 месяца — 1299 Stars
* 12 месяцев — 3999 Stars

### 1.3 Создание инвойса

Использовать Telegram Bot API / Stars Payments.

При успешной оплате Telegram присылает `successful_payment`.

### 1.4 Обработка успешной оплаты

После получения события:

* создать запись в БД `payments`;
* активировать подписку пользователя;
* отправить сообщение:

> Оплата получена. Подписка активирована до DD.MM.YYYY.

# 3. База данных

## Таблица payments

```sql
CREATE TABLE payments (
    id UUID PRIMARY KEY,
    user_id UUID NULL,
    telegram_user_id BIGINT NULL,
    provider VARCHAR(32) NOT NULL,
    external_id VARCHAR(128) NOT NULL,
    amount NUMERIC(10,2) NOT NULL,
    currency VARCHAR(16) NOT NULL,
    tariff VARCHAR(32) NOT NULL,
    status VARCHAR(32) NOT NULL,
    tx_hash VARCHAR(128) NULL,
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    paid_at TIMESTAMP NULL
);
```

## Таблица subscriptions

Если уже существует — использовать её.

Нужны поля:

```sql
user_id UUID PRIMARY KEY,
plan VARCHAR(32),
active_until TIMESTAMP,
status VARCHAR(16)
```

# 4. Логика активации подписки

## Тарифы

| Тариф     | Длительность |
| --------- | ------------ |
| monthly   | 30 дней      |
| quarterly | 90 дней      |
| yearly    | 365 дней     |

Алгоритм:

* если подписка активна — продлить от `active_until`;
* если не активна — продлить от текущего времени.

# 6. USDT TRC20

## Цель

Сделать простой MVP без автоматического блокчейн-индекса.

### Конфиг

```env
USDT_TRC20_ADDRESS=TXXXXXXXXXXXXXXXXXXXXXXXX
USDT_CONFIRMATIONS=1
```

### API

#### Получить реквизиты

```http
GET /api/payments/usdt/address
```

Ответ:

```json
{
  "address": "T...",
  "network": "TRC20"
}
```

#### Подтвердить оплату вручную

```http
POST /api/payments/usdt/confirm
```

Тело:

```json
{
  "tx_hash": "...",
  "email": "user@example.com",
  "tariff": "monthly"
}
```

### Админ-проверка

Сервис проверяет транзакцию через Tron API и при успехе:

* создаёт запись в `payments`;
* активирует подписку.

# 11. Безопасность

* webhook только POST;
* ограничение размера тела 1 MB;
* таймаут 5 сек;
* идемпотентность по `external_id`;
* запрет повторной обработки одного платежа.

# 12. Результат

После выполнения должно работать:

1. Пользователь пишет боту `/buy`.
2. Оплачивает Stars.
3. Backend автоматически активирует подписку.
4. Пользователь получает подтверждение.
5. На сайте доступна альтернативная оплата USDT TRC20.
