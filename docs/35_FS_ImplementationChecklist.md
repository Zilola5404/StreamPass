## 1. Приоритетный порядок работ

| Очередь | ID | Задача | FS | Зачем |
|---------|-----|--------|-----|-------|
| 1 | **BL-040** | Live ЮKassa + возврат/poll статуса | E06 Must | Без оплаты нет SaaS |
| 2 | **BL-041** | Logout | E05/E10 Must | Базовая безопасность аккаунта |
| 3 | **BL-045** | Auto Mode = Автовыбор сервера | E02 Must | Сейчас UI может врать |
| 4 | **BL-046** | Reconnect при смене сервера | E04 Must | Выбор сервера бесполезен mid-session |
| 5 | **BL-047** | UX автосмены relay | §6 Must | ТЗ §22 degradation |
| 6 | **BL-044** | Статистика | E03 Must | Сейчас заглушка |
| 7 | **BL-042** + **BL-043** | Сброс пароля, профиль, удаление | E01/E10 | Аккаунт SaaS |
| 8 | **BL-048** | Тарифы + история + active_until after cancel | E06 | Биллинг «как продукт» |
| 9 | **BL-053** | Замер SLA на устройстве | §5 / ТЗ §22 | Доказательство готовности |
| 10 | BL-049…054 | Устройства, admin Premium, уведомления, тема | Should | Post-MVP polish |

Связь: **BL-030** (auto-renewal) остаётся Blocked до закрытия **BL-040**.

## 5. Definition of Done для «SaaS по FS»

Считать продуктовый контур закрытым, когда:

1. [ ] BL-040 — реальная оплата и ACTIVE без ручного SQL  
2. [ ] BL-041, BL-045, BL-046, BL-047 — Home/аккаунт без дыр UX  
3. [ ] BL-044 — статистика не заглушка  
4. [ ] BL-042, BL-043 — пароль/профиль/удаление  
5. [ ] BL-053 — цифры SLA на физическом устройстве  
6. [ ] QA прогнал матрицу ERR-* из FS §8  

Платформы Windows/iOS/macOS (BL-023…025) — отдельно, не блокер Android SaaS.
